# Isomorphic Pattern Matcher in the C Language
- build with make or gmake
- run with ./isomorphic "hot" isomorprhic.c

./isomorphic "hot" isomorphic.c      
Isomorphic pattern match: hot isomorphic.c

# Install
- as superuser 
  cp isomorphic /usr/local/bin
- Use isomorphic system wide.
